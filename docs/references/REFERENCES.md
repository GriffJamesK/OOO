# References

Drop reference images (`.png`, `.jpg`, `.jpeg`, `.gif`, `.webp`) into this folder, subfolders allowed, then add a section below for each one. Agents read this file and look at every image before writing the GDD, and they follow your notes over their own reading of the picture.

- One `## <file name>` heading per image, using its path inside this folder (e.g. `## mood/fog-alley.jpg`). A test checks that every image has a section and every section has an image.
- **Use for:** which part of the game this informs: art direction, level layout, a mechanic, UI, camera, scale.
- **Pay attention to:** the specific details to take from it.
- **Ignore:** anything in the image that should *not* carry over.
- Leave a field out if it doesn't apply. Notes under **General** apply to every image.
